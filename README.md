# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案前端：记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面包含纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 核心流程

- **外勤离线登记 → 回网合并**：离线登记的破损区域与补线色号先存为本地草稿（localStorage），回网后按「校验档案 → 合并破损区域 → 合并补线色号 → 追加证据 → 登记材料消耗」五步合并进工坊工序。
- **只补证据不覆盖**：外勤记录遇到同名破损区域或已确认色号的工序时，只追加证据，不覆盖工坊数据。
- **并发冲突**：同一纹样被两名修复师同时保存时，先确认的工序保留，后到的修改列入冲突列表（可用工序行的「并发模拟」按钮演示）。
- **色卡批号更新**：未完成工序按新批号重算；已入库记录仍展示当时色卡快照。
- **断点续传**：合并失败保留本地草稿，恢复后从失败步骤续传；材料消耗按幂等键去重，不重复追加（用「故障注入」下拉演示）。
- **数据迁移**：旧数据缺色卡批号，首次启动按默认色卡回填；历史修复批次照常打开。

## 演示路径

1. 首次打开可见「数据升级完成」横幅（v1 → v2 迁移回填）。
2. 点右上角切到「离线（外勤模式）」，在右栏登记一条破损 + 补线色号，再切回在线自动合并。
3. 在「故障注入」里选一步后同步，观察草稿保留、步骤断点与续传（选最后一步可看到材料消耗幂等去重）。
4. 在任意工序点「并发模拟」，再点「确认色号」，后到的修改会进入冲突列表。
5. 在色卡面板点「更新批号」，在修档案的未完成工序批号重算；打开批次 RB-2025-12 的 CAR-001，仍显示入库时的色卡批号。
